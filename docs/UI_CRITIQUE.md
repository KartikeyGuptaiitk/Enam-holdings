# Baseline critique
1. The identity is restrained, but nearly every surface has the same visual weight.
2. Repeated full results tables turn a shortlist into a long accounting scroll.
3. Five movers conceal the rest of the portfolio.
4. The portfolio has no spatial identity or at-a-glance breadth.
5. Headlines compete with metadata instead of commanding attention.
6. Tiny source controls feel secondary to the claim they substantiate.
7. Green-on-green is too subdued for an urgent signal.
8. There is no paper theme for daylight reading.
9. The large desktop canvas loses the intimate one-person desk concept.
10. Watch opens with configuration rather than the investor's inbox.
11. Alert thresholds lack a visual sense of time.
12. Ask starts in a long result rather than explaining its available lenses.
13. A bare credibility number overstates the breadth of a narrow heuristic.
14. Source sheets lack keyboard containment and an obvious citation action.
15. Search, preferences and gesture discovery are absent.
